# Module 11 Assignment: Data Visualization with Matplotlib

This repository contains my work for Module 11. The assignment focuses on creating visualizations with Matplotlib to analyze sales, advertising, customer demographics, purchase behavior, and market share for a fictional company called SunCoast Retail.

## Files Included

- `module11-assignment.py`

## What I Practiced

In this assignment, I practiced creating line charts, bar charts, stacked bar charts, scatter plots, histograms, box plots, and pie charts. I also practiced using Pandas with Matplotlib to summarize data visually and explain patterns in sales, advertising efficiency, customer age, product categories, and store locations.
